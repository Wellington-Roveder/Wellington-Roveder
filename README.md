### 📊 [SentinelLog](https://github.com/Wellington-Roveder/SentinelLog-game-price-monitor) &nbsp; ![](https://img.shields.io/badge/CONCLUÍDO-555?style=flat-square)

`Python` `FastAPI` `SQLite` `N8N` `Streamlit` `ETL`
